# Language is a tool to create reality, not only to describe it

> Most people think of language as a tool to describe reality. What they miss is that language is also a tool to create reality.

Dave's example is JFK's declaration — *we will put a man on the moon and return him safely to the earth by the end of the decade*. Note the structure: who will do what by when. It was not a forecast about a reality that already existed. It brought into being a reality in which a decade of work, funding and national attention made sense.

This is why a desired future state has to be **declared** rather than privately held. A declaration commits, aligns and organises other people's behaviour in a way that a description never does — which is also why it feels exposing to make one. Andrew presses exactly here: a DFS puts a number on you, publicly, that you might miss.

The same principle runs underneath unarguable language from the other direction. Saying *we should go to the party* doesn't just report a position, it creates one — Jesse notices he gets dug in and starts arguing his way down that path. Saying *I'd like to go* creates a different reality, one where two people can problem-solve. → Speaking Unarguably
