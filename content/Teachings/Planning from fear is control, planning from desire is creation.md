# Planning from fear is control, planning from desire is creation

Andrew asks the obvious follow-up: if overwhelm is future-tripping, how does that square with the planning he's been told to do? Dave's answer keeps the planning and changes what it's for.

> Control is a word I use very specifically, because we can't control the future. We can influence it.

The two versions, same activity:

> When we're scared, we're literally trying to control the future to keep us safe. That's a really different place to come from than: oh, I want to create this trail in my backyard, so let me make a plan for how to do that, and I'll go work the plan and see what happens — and I'll learn, oh, my plan sucked, or my plan was great.

Note that only the second version can learn anything. A plan made to prevent a feeling must succeed, so its failure is a catastrophe; a plan made to create something is a hypothesis, and its failure is data. → [[Experiments Instead of Failure]]

Jesse's version at company scale is the same distinction applied to annual planning:

> "This thing we kept doing didn't work, let's try something different, because we want to win and play this game" — versus "we must hit this number this quarter, get the plan perfectly accurate, and then we don't hit it and we should all go home because we're failures."

His defence of goals is worth keeping, because none of this is an argument against them:

> Setting goals and planning is helpful — it lets you prioritise, it lets you set intention, it gets everyone on the same page. But it's not because you're trying to hit this exact number perfectly and stick the landing, otherwise you're a failure.

→ [[Desired Future State (DFS)]]
